## Criando Documentação JAVA

#### Terminal
```
javadoc -d doc -sourcepath src poo/src/semana04/Calculadora.java
```

- Passar o caminho da classe a ser documentada, podendo ser mais que uma só classe

- Para documentar o package inteiro basta passar o caminho do package com todas as Classes

```
javadoc -d doc -sourcepath src poo/src/semana03/*
```
